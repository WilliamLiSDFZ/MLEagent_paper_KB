# Toward Availability Attacks in 3D Point Clouds

**Source**: https://proceedings.mlr.press/v235/zhu24i.html

## [POSITIVE] Feature Collision Error-Minimization (FC-EM)
A novel availability attack method for 3D point clouds that replaces the cross-entropy loss with a class-wise feature similarity (collision) loss during inner minimization of bi-level optimization, creating shortcuts in the feature space by encouraging intra-class feature concentration and inter-class feature dispersion, while using Chamfer distance as regularization.

**Delta**: 27.67% test accuracy on ModelNet40 (PointNet), vs 82.98% for EM and 86.22% for REG-EM; 0.000 F1-score on IntrA with PointNet++ and DGCNN
**Condition**: 3D point cloud availability attacks across ModelNet40, ScanObjectNN, IntrA medical dataset, and BFM-2017 face dataset

**Evidence**: "our FC-EM achieves the lowest test accuracy (Acc) compared with all other baselines and exhibits suitable imperceptibility (measured by Chamfer distance Dc) and Hausdorff distance Dh). Consequently, it exhibits the worst generalization and causes strongest poison."

## [NEGATIVE] Chamfer Distance Regularization (REG-EM)
Extending 2D error-minimization (unlearnable examples) to 3D point clouds by adding Chamfer distance as a regularization term in the bi-level min-min optimization, replacing the lp-norm constraint used in 2D.

**Delta**: 86.22% test accuracy on ModelNet40 PointNet (vs 90.70% clean), barely reducing accuracy compared to clean baseline
**Condition**: 3D point cloud availability attacks when distance regularization is applied to bi-level optimization

**Evidence**: "although REG-EM and REG-AP successfully achieve imperceptibility, they fail to reduce model's accuracy on test data, remaining Acc even larger than 70%."

## [NEGATIVE] Regularized Adversarial Poisons (REG-AP)
Extending 2D adversarial poisons (AP) to 3D point clouds by incorporating Chamfer distance as a regularization term, weakening the adversarial perturbation generation.

**Delta**: 75.32% test accuracy on ModelNet40 PointNet, weaker than unregularized AP (69.37%)
**Condition**: 3D point cloud availability attacks using adversarial poison generation with distance regularization

**Evidence**: "when extending AP to REG-AP, the addition of a distance regularization term weakens δ rather than strengthens it. This occurs because, during the iterative process of REG-AP, once the adversarial attack succeeds, the optimization focus in Eq. (4) shifts towards minimizing the regularization term, attempting to reduce δ."

## [NEGATIVE] lp-norm constrained Error-Minimization (EM)
Direct application of 2D unlearnable examples (bi-level min-min error-minimization) to 3D point clouds using lp-norm constraints on perturbations.

**Delta**: 82.98% test accuracy on ModelNet40 PointNet (vs 90.70% clean), with high Chamfer distance (29.7e-4) indicating poor imperceptibility
**Condition**: 3D point cloud availability attacks; reduces accuracy somewhat but produces visually perceptible outliers

**Evidence**: "Poisons generated by EM, AP, AP-T and REG-AP-T exhibit conspicuous outliers, thus lacking imperceptibility."

## [NEGATIVE] lp-norm constrained Adversarial Poisons (AP)
Direct application of 2D adversarial poisons to 3D point clouds using lp-norm constraints, generating perturbations via stronger adversarial attacks on a pre-trained source classifier.

**Delta**: 69.37% test accuracy on ModelNet40 PointNet but 89.26% on PointNet++, inconsistent results with high Chamfer distance
**Condition**: 3D point cloud availability attacks; inconsistent across models and lacks imperceptibility

**Evidence**: "Poisons generated by EM, AP, AP-T and REG-AP-T exhibit conspicuous outliers, thus lacking imperceptibility."

## [NEUTRAL] Targeted Adversarial Poisons (AP-T)
Targeted version of adversarial poisons applied to 3D point clouds with lp-norm constraints, using targeted adversarial attacks for poison generation.

**Delta**: 61.95% test accuracy on ModelNet40 PointNet but with high Chamfer distance (26.7e-4) indicating poor imperceptibility
**Condition**: 3D point cloud availability attacks; achieves some accuracy reduction but lacks imperceptibility

**Evidence**: "Poisons generated by EM, AP, AP-T and REG-AP-T exhibit conspicuous outliers, thus lacking imperceptibility."

## [NEGATIVE] Bi-level optimization degeneracy under distance regularization
A failure mode where introducing Chamfer distance regularization into bi-level min-min optimization causes the optimal perturbation to degenerate toward zero, rendering poisons ineffective. Proven theoretically via Theorem 4.1 and Corollary 4.3.

**Delta**: REG-EM test accuracy remains near clean baseline (86.22% vs 90.70% clean on ModelNet40 PointNet)
**Condition**: Occurs when Chamfer distance regularization is added to bi-level optimization for 3D point cloud poisoning, especially when L_cls is cross-entropy (which converges near zero)

**Evidence**: "Theorem 4.1 indicates that when the gap of min_θ L_cls(D;θ) − min_{δ,θ} L_cls(D_δ;θ) is extremely small, the optimal perturbation δ* is subject to a very limited distance constraint, significantly reducing the poisoning power."

## [POSITIVE] Feature collision loss (L_fc)
A class-wise cosine similarity loss used during inner minimization of bi-level optimization, replacing cross-entropy. It maximizes intra-class feature similarity and minimizes inter-class feature similarity, creating shortcuts in feature space with different optimization directions than the outer cross-entropy minimization.

**Delta**: FC-EM achieves 27.67% vs REG-EM 86.22% on ModelNet40 PointNet; feature collision loss fails to converge under standard training, maintaining large gap Δ needed for effective perturbations
**Condition**: Inner minimization step of bi-level optimization for 3D point cloud availability attacks

**Evidence**: "when vanilla training a network using the cross entropy loss L_cls, the feature collision loss L_fc fails to converge and even increases. In other words, while minimizing L_cls and L_fc both aim to create shortcuts, they do not optimize towards the same direction."

## [POSITIVE] Reduced inter-class cosine similarity in weight matrix
FC-EM's feature collision loss reduces cosine similarity between rows of the last-layer weight matrix, which by Theorem 5.3 implies stronger linear separability of poisoned data and thus more effective poisons under a fixed Chamfer distance budget.

**Delta**: FC-EM yields smaller cosine similarities compared to EM and REG-EM (shown in Figure 3b)
**Condition**: Analysis of last-layer weight matrix cosine similarity under different poisoning methods

**Evidence**: "FC-EM indeed yields smaller cosine similarities compared to EM and REG-EM. According to Theorem 5.3, this implies that if the Chamfer distance is constrained, FC-EM exhibits stronger linear separability than EM and REG-EM."

## [POSITIVE] Transferability of FC-EM across victim models
Evaluating whether poisons generated on one point cloud model (PointNet, PointNet++, DGCNN) transfer to degrade other models without retraining.

**Delta**: All cross-model test accuracies remain below 40% on ModelNet40
**Condition**: Cross-model transferability on ModelNet40 dataset

**Evidence**: "Results presented in Table 4 shows the decent transferability of FC-EM, as all the test accuracy remains consistently below 40%. Our FC-EM is stable, displaying small sensitivity in both the source and victim models."

## [POSITIVE] Defense robustness of FC-EM
Evaluating FC-EM against multiple defense strategies including PGD adversarial training, TRADES, Mixup, Rsmix data augmentation, and IF-Defense (3D-specific defense).

**Delta**: FC-EM achieves lowest test accuracy under all defenses: 49.59% (PGD), 52.80% (TRADES), 65.32% (Mixup), 51.86% (Rsmix), 75.73% (IF-Defense) on ModelNet40 PointNet
**Condition**: Evaluated on ModelNet40 with PointNet under six defense methods

**Evidence**: "The results provided in Table 5 demonstrates that FC-EM outperforms all other availability attacks in all defense methods."

## [NEUTRAL] Uniform 1024-point sampling
Uniformly sampling 1,024 points from each point cloud for both attack generation and classification evaluation across all datasets.

**Delta**: No specific delta reported; used as standard setup
**Condition**: Applied uniformly across all experiments and datasets

**Evidence**: "Across all datasets, we uniformly sample 1,024 points for attacks and classification."

## [POSITIVE] Distance regularization strength beta sensitivity
The balancing hyperparameter β between classification loss and Chamfer distance regularization. FC-EM shows sensitivity to β (indicating active regularization), while REG-EM shows insensitivity (indicating degeneracy).

**Delta**: FC-EM poisons vary with β; REG-EM shows consistent Chamfer distance and test accuracy regardless of β
**Condition**: Ablation study on regularization strength for REG-EM vs FC-EM

**Evidence**: "In contrast, poisons crafted by FC-EM are more vulnerable to the balancing hyperparameter β, demonstrating resilience against poison degeneracy."
