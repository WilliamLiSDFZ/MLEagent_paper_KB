# Large Scale Canopy Height Estimation

This skill covers large-scale estimation of forest canopy height using satellite imagery (particularly high-resolution optical sensors like GEDI lidar as ground truth combined with Sentinel-2 or similar multispectral data) and deep learning models to produce spatially continuous, global or regional-scale canopy height maps. Applications include forest biomass assessment, carbon stock estimation, and ecosystem monitoring
