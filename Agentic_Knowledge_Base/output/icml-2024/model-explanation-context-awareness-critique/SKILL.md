# Model Explanation Context Awareness Critique

**This skill covers critiques and frameworks arguing that explanations of vision model predictions (e.g., saliency maps, attribution methods) are misleading or incomplete without explicitly specifying the deployment context, intended use case, and evaluation criteria.** It examines how the validity and utility of explanation methods depend on contextual factors such as the task definition, user needs, and potential failure modes
